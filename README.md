# Backend Auth BoilerPlate with Clerk

### This is a backend boilerplate using Clerk as authentication with MongoDb as database

### Tech stack
- Bun
- Typescript
- ExpressJs
- Clerk

### Project structure
    src
    |- controllers
    |- middlewares
    |- models
    |- routes
    |- index.ts

### Scripts
- <code>bun dev</code>
- <code>bun start</code>
